# 正文配音（千问拆台词 → IndexTTS2 音色克隆）

酒馆插件：把**当前楼层正文**交给千问27B 拆成「谁说的什么」，再按**每个角色的参考音色**逐句用 IndexTTS2 克隆出配音，最后可合并成一条。

## 依赖：本机 H3 工作台（默认 `http://127.0.0.1:8899`）

| 接口 | 用途 |
|---|---|
| `GET /api/tts/voices` | 已有音色参考 |
| `POST /api/tts/upload?name=xxx.wav` | 上传音色参考（wav/mp3/ogg/flac/m4a） |
| `POST /api/tts/run` | `{text, ref, emoText}` → 一句音频 |
| `POST /api/tts/merge` | `{names:[...]}` → 用 ffmpeg 合并成一条 |
| `POST /v1/chat/completions` | 千问拆台词（JSON 数组） |

音频落在 `D:\h3工作台\tts\input`（音色参考）和 `tts\output`（生成结果）。

## 安装

酒馆 → 扩展 → 安装扩展 → 填：

```
https://github.com/hhdsz0807/sillytavern-tts
```

装好刷新，顶部图标条会多一个 **🎤**；扩展设置里也有「正文配音」入口。

## 用法

1. 点 🎤 打开面板
2. **音色槽**：默认「旁白 + 角色1」
   - 一行 = 角色名 + 参考音频（点「传」上传 10–20 秒干净人声）
   - 有几个角色就点「+ 加角色」（旁白算一个，所以 4 个角色 = 5 个槽）
3. 选楼层 → 点「看正文」确认抓对了
4. 点 **① 拆台词**：千问输出 `[{speaker, text, emo}]`，可直接改
5. 点 **② 配音**：按 speaker 找对应音色，逐句并发克隆（并发 1–4）
6. 点 **③ 合并**：所有已生成的句子按顺序拼成一条，可试听/下载

## 情绪

每句带 `emo`（平静/开心/疑惑/害羞/生气/难过/紧张/惊讶），会写进 IndexTTS2 的 `emo_text`；面板里「用情绪」可关。

## 成本参考（实测）

| 项 | 币 | 时间 |
|---|---|---|
| 拆台词（千问，40 句内） | 3–6 | 20–40s |
| 单句配音（约 10 字） | **5** | 25–30s |
| 单句配音（约 20 字） | 16 | 80s |

一段 10 句对话 ≈ 50–80 币、2–3 分钟（并发 2）。

## 已知限制

- 一句一任务，句子越多越贵；建议 40 句以内
- 音色参考越干净越像（别带背景音乐）
- 手机 APK 目前没有 `/api/tts/*`，手机端需连电脑的 8899（把 H3 地址填电脑局域网 IP）
